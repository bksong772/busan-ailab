## 🎯 1. 전략 핵심 — 왜 마케팅이 아니라 영업인가

### 사실 정리

1. **부산AI코딩스쿨 출강 기관 100+개** 이미 확보 (2023~2025)
2. **진완** 대면 영업 능력 확인됨 (수리공의온도·AI코딩스쿨 동시 가동)
3. **김미선 대표** 등 매칭 파트너 노드 확보 중 (4/17 미팅)
4. **부산AI랩 사이트** 이미 80% 완성 (busan-ailab.vercel.app)
5. **병근 에너지** 마케팅 채널 확장 더 못 견딤 → 브런치 중단 결정 (4/16)

### 결론
> **신규 채널 만들 시간에 진완이 전화 50통 더 돌린다**
> 100+ 기관 담당자 = 잠재 리드. 이미 연락처·신뢰 확보됨. 다시 접촉하면 **전환율 ≫ 콜드 리드**.

## 📋 2. 리드 풀 3단계 (우선순위 순)

### Tier A: 기존 출강 기관 재접촉 (⭐ 메인) — 전환율 최고

- **규모**: 100+개 기관, 담당자 전화번호·이메일 확보
- **접근 방식**: "작년 AI 교육 잘 들으셨죠? 올해는 교직원·직원 **업무 자동화** 진단 서비스도 시작했는데, 한 번 보여드릴까요?"
- **전환 타겟**: 공공기관·학교 행정실·도서관·복지관 우선 (이미 예산 집행 경험 있음)
- **진완 작업**: 주 30~50통 콜 (하루 10통 페이스)
- **기대 전환**: 100건 중 5~10건 **진단 50~100만원** 수주 가능 → 5월 누적 3건이면 **150~300만원**

### Tier B: 김미선 대표 소개 건 (고품질 리드)

- **접근 방식**: 4/17 미팅 결과 기반, 김 대표가 소개하는 기관·학교부터 순차 접촉
- **수수료**: 김 대표 요구 기준 (10~15%) — 미팅에서 확정
- **전환 타겟**: 진로교육 맥락 → 학교·공공기관 AI·업무 자동화 수요 변환
- **진완 작업**: 소개 들어오는 대로 24시간 내 컨택
- **기대 전환**: 소개 5건 → 1~2건 수주 → **진단 100~200만원**

### Tier C: 공공기관 Top 5 직접 콜드콜 (신규 개척)

- **타겟 리스트** (이미 관계자 있는 기관 우선):
  1. **부산교통공사** (2026년 5·10월 AI코딩 교육 수주 확정) — 연계 쉬움
  2. **부산경제진흥원** (2026년 5월 수주) — AX 제안 타이밍 Good
  3. **동래청년어울림** (2026년 5월 수주) — 신규 관계
  4. **북구진로교육원** (2026년 5월 수주) — 신규 관계
  5. **부산시청·구청 혁신과** — 미개척이지만 AX 예산 가능성 높음
- **접근 방식**: 교육 출강 마지막 차시 **"AX 진단 30분 보너스"** 끼워넣기
- **진완 작업**: 5월 교육 중 "30분 진단 보너스" 제안 → 담당자 반응 확인
- **기대 전환**: 5건 중 2~3건 진단 수주 → **100~300만원**

## 💰 3. 5월 매출 시뮬레이션

| Tier | 상품 | 단가 | 목표 건수 | 예상 매출 |
|------|------|------|----------|----------|
| A (기존 기관 재접촉) | 진단 | 75만원 | 2건 | 150만원 |
| B (김미선 소개) | 진단 | 100만원 | 1건 | 100만원 |
| C (공공기관 Top 5) | 진단 | 75만원 | 2건 | 150만원 |
| **개발 1건** (진단 → 전환) | 개발 | 400만원 | 1건 | 400만원 |
| **유지보수** (개발 후 즉시) | 월 운영 | 월 30만원 | 1건 | 30만원 (첫달 무료 or 30) |
| (여유분) | - | - | - | 170만원 |
| **합계 (5월)** | | | | **약 1,000만원** |

**핵심**: 진단 5건 → 1건이라도 개발 전환되면 **400만원 단일 매출**로 절반 커버.
→ 5월 목표는 "**개발 1건 전환**"에 총력 집중.

## 📞 8. 진완 콜드콜 스크립트 (5월 전용)

### 케이스 1: 기존 출강 기관 재접촉
```
"안녕하세요, 부산AI코딩스쿨 김진완입니다.
작년에 [기관명]에서 AI교육 진행해드렸었죠.

올해부터 저희가 '부산AI랩' 이름으로
교직원·직원 업무 자동화 진단·구축 서비스도 같이 하고 있어서,
간단히 소개드리려고요.

혹시 최근에 엑셀·보고서·공문 처리 같은 반복 업무 때문에
시간 많이 쓰시는 부서 있으세요?
30분 정도 무료로 진단해드릴 수 있습니다."
```

### 케이스 2: 김미선 대표 소개 건
```
"안녕하세요, 부산AI코딩스쿨·부산AI랩 김진완입니다.
김미선 대표님께서 [기관명] 추천해주셔서 연락드렸어요.

저희는 AI 교육 출강이랑 업무 자동화 진단 두 축으로 하고 있고,
교육은 차시당 10~20만원, 자동화 진단은 50~100만원대예요.

[기관명]에 어떤 게 더 맞을지 한 번 간단히 뵈어도 될까요?"
```

### 케이스 3: 공공기관 Top 5 콜드콜
```
"안녕하세요, 부산AI코딩스쿨·부산AI랩 김진완입니다.
[기관명] 혁신과/기획과 담당자 연결 부탁드립니다.

저희가 작년에 부산교통공사·경제진흥원 등에서
업무 자동화 진단·교육 프로젝트 진행했던 경험이 있어서,
[기관명]에도 비슷한 니즈가 있는지 여쭤보려고 연락드렸어요."
```
