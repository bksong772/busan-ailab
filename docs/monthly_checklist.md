# 부산AI랩 4월 실행 체크리스트

> 순서대로 진행. 완료하면 [ ] → [x]. 막히면 그냥 두고 다음으로.
> "체크리스트 현황 봐줘" 하면 다음 단계 안내받을 수 있음.
>
> 🧠 = 지금 이 세션에서 (전략/콘텐츠/자동화)
> 💻 = 개발 터미널에서 (Framer / 코드 작업)

---

## PHASE 1. 기반 세팅 (Week 1)

### 시스템 구축 🧠
- [ ] Notion CRM DB 생성 (리드 DB + 수강생 DB) (30분)
- [ ] Tally 수강 문의 폼 생성 (30분)
- [ ] Tally 무료 자료 신청 폼 생성 (리드 마그넷용) (30분)
- [ ] 솔라피 계정 개설 + 알림톡 템플릿 심사 신청 (1시간, 심사 2~3일 소요)
- [ ] Make.com 계정 생성

### 자동화 연결 🧠
- [ ] Make.com: Tally → Notion CRM 자동 등록 시나리오
- [ ] Make.com: 신청 즉시 알림톡 자동 발송 시나리오
- [ ] Cal.com 상담 예약 페이지 생성 + 구글 캘린더 연동

### 사이트 보완 (busan-ailab.vercel.app) 💻
> 현재 사이트 완성도 높음. 아래 항목 추가로 개인 고객 전환율 강화.

**신뢰도 강화**
- [ ] 수강생 후기 섹션 추가 (사진 + 이름/직책 + 한 줄 후기 3~5개)
- [ ] 수강생 만족도 수치 추가 (예: "수강생 92% 업무 적용 성공")

**개인 고객 진입장벽 낮추기**
- [ ] 가격대 공개 섹션 추가 (예: "초급 49만원부터 / 기관 출강 별도 문의")
- [ ] 커리큘럼 상세 펼침 (아코디언 형식 — 각 프로그램 주차별 내용)

**오프라인 밀착 강점 강화**
- [ ] 오시는 길 섹션 추가 (주소 + 구글맵 임베드 + 대중교통 안내)

**UX 개선**
- [ ] 모바일 전체 점검 (버튼 크기·텍스트 길이·앵커 링크 동작)
- [ ] 헤더에 "개인 학습 / 기관 교육" 탭 분리 (사용자 여정 명확화)

### 랜딩페이지 제작 💻
- [ ] Tally 폼 링크 랜딩페이지에 연결
- [ ] 모바일 반응형 확인

## AI에게 요청 가능한 것

```
"랜딩페이지 카피 써줘"     → Framer용 섹션별 카피
"블로그 포스팅 초안"        → SEO 최적화 포스팅
"체험 클래스 커리큘럼"      → 90분 수업 구성
"진완 영업 스크립트"        → 전화/대면 각 1개
"B2B 제안서 써줘"          → 1장짜리 제안서
"알림톡 메시지 써줘"        → 신청 확인/리마인더
"인스타 카피 써줘"          → 게시물 캡션 5개
"체크리스트 현황 봐줘"      → 다음 단계 안내
```
