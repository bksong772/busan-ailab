# AX그라운드 구글 서치콘솔(GSC) 등록 가이드

> 목적: AX그라운드(axground.vercel.app) 구글 색인 가속 + 검색 성과 모니터링.
> 사이트 SEO는 이미 준비됨(sitemap·Article schema·메타·canonical). **GSC 등록만 하면 구글 노출 시작.**

## STEP 1 — 속성 추가
1. `search.google.com/search-console` 접속 (사업용 구글 계정 bksong772.bgs@gmail.com)
2. 좌상단 "속성 추가" → **"URL 접두어"** 선택
3. 입력: `https://axground.vercel.app`

## STEP 2 — 소유확인 (제일 쉬운 방법)
- "HTML 태그" 방식 선택 → 구글이 `<meta name="google-site-verification" content="...코드..." />` 를 줌
- ⚠️ 이 사이트는 Vercel 배포라 코드에 meta를 넣어야 해 → **그 content 코드만 복사해서 나(클로드)한테 주면** 내가 `layout.tsx`(metadata.verification)에 넣고 배포할게 → 그 다음 GSC에서 "확인" 누르면 끝.
  - (대안: 커스텀 도메인 쓰면 DNS TXT 방식도 가능)

## STEP 3 — sitemap 제출
- 인증 후 좌측 메뉴 "Sitemaps" → `sitemap.xml` 입력 → 제출
- (이미 `axground.vercel.app/sitemap.xml`에 홈·insight·cases·진단 등 다 포함돼 있음)

## STEP 4 — 색인 요청 (선택, 가속)
- 상단 "URL 검사"에 주요 페이지 입력 → "색인 생성 요청"
  - axground.vercel.app/ (홈)
  - /insight/ax-where-to-start-small-business-2026
  - /insight/sonyeo-catering-ax-case
  - /cases

## 참고
- 구글은 사이트 콘텐츠를 잘 색인 → GSC 등록 시 며칠~몇 주 내 "AX", "소상공인 AI", "업무 자동화 부산" 등으로 노출 시작
- 네이버 노출은 별개(자사 블로그 우대) → 네이버는 8월 이후 AX그라운드 네이버 블로그로 보강 검토
- 커스텀 도메인(axground.co.kr 등) 구매하면 GSC·sitemap·canonical 다 그 도메인으로 재설정 필요(그때 알려줘)
- 부코딩 사이트 Footer에 AX그라운드 크로스링크 추가함(도메인 권위 전달)

## 병근이 줄 것
1. GSC HTML 태그 content 코드 → 나한테 (사이트에 박고 배포)
2. (선택) 커스텀 도메인 살 건지
