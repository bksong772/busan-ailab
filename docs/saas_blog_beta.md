## 기술 결정 (5/8)

| 항목 | 결정 |
|------|------|
| 백엔드 워커 | **Python single stack** (`bot.py`). n8n ❌ — 자영업자 N명 = 워크플로우 N개 = 관리 지옥 |
| 발행 | Playwright Python (수리공의온도·중현초 패턴 재사용) |
| 글 생성 | Anthropic SDK (Python) |
| DB | Google Sheets (`gspread`) → 5명+ 시 Supabase |
| 자영업자 facing | Apps Script Web App (사진 업로드 페이지, Drive 자동 저장) |
| 검수 정책 | **사전 검수 ❌, 발행 후 카톡 알림** ("자영업자 = 확인만") |
| 호스팅 | 맥미니 cron (5명까지) → 5명+ 시 VPS |
| 카톡 알림 | 베타: 진완 폰 1:1 / 5명+: 카카오 비즈니스 채널 봇 |

## 멀티 테넌시 모델 (확장 핵심)

```
[Sheets — 자영업자_master]
| 사장님ID | 이름      | 블로그URL    | ID/PW   | Drive폴더 | 발행요일 | 키워드  |
| 001     | 수리아저씨 | blog.naver/x | (vault) | drv_abc  | 화/금   | 집수리,|
| 002     | 김미용실   | blog.naver/y | (vault) | drv_def  | 수/토   | 미용,  |

[Python 워커 (cron 매시간)]
for 사장님 in master:
    if 지금 == 사장님.발행시점:
        글 = claude.generate(사장님.정보, 사장님.키워드)
        사진 = drive.match(사장님.Drive폴더)
        playwright.publish(사장님.블로그계정, 글, 사진)
        notify(사장님.카톡, "올렸어요")
```

**N명 추가 = Sheets 한 줄. 코드 0줄 변경.**

## 카톡 메시지 초안 (병근이 아저씨에게)

```
사장님 안녕하세요!

저번에 블로그 마케팅 19만원 내는데도 글도 잘 안 올라가고
효과 없다고 하신 거 마음에 남아서 연락드려요.

마침 저희가 AI가 키워드 찾고 글 써서
네이버 블로그에 자동으로 올려주는 프로그램을 만들었는데,
사장님께 무료로 1편 먼저 보여드리고 싶습니다.

[사장님이 주실 것]
- 블로그 주소
- 블로그 ID/PW (글 발행용)
- 시공 사진 1~2장 (카톡)

[저희가 해드릴 것]
- 블로그 분석 + 키워드 조사
- 글 1편 + 사진 매칭해서 발행
- 1~2주 후 노출수·댓글·문의 결과 리포트

효과 좋으면 정식으로 월 5만원에 자동 운영해드리고,
별로면 그냥 무료 케이스로 끝나요.
한번 해보실래요?
```

**활용 팁**:
- 병근/진완 누가 보낼지 결정 (아저씨와 친밀도 높은 사람)
- 가격(월 5만원) 언급은 효과 검증 후 강조해도 OK — 첫 메시지에서 빼도 됨
- ID/PW 부담스러워하면 → "또는 글 보내드리면 사장님이 직접 올려주셔도 됩니다"로 옵션 추가
