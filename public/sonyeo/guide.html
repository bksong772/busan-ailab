단계별 사용법

주황 → 대표님이 하실 일   초록 ✓ 자동으로 되는 일

📥
STEP 01

신청 받기

대표님 1분
대표님이 하실 일
  • ① 카드 리스트에서 📧 고객 메일 발송 직접 클릭 → 접수 안내 메일 자동 발송
  • ② 신청 카드 클릭 → 상세 내용 확인 (담당자·인원·예산·협의)
  • ③ 📞 통화 상담 시작 → Step 02 클릭 후 통화하면서 Step 02 진행
자동으로 되는 일
  • 아임웹 신청 → 5분 안에 시트에 자동 적재
  • 대시보드 좌측 사이드바에 "신규 ●" 표시
  • 임박한 행사는 빨간색 D-day 뱃지
  • ✅ 신청자에게 SMS 자동 발송 — "접수 완료 + 카톡 채널 링크" (아임웹 자체)
  • (선택) SMS 대신 카톡 알림톡으로 받게 하기 — 솔라피 연결 시 (영업일 2~3일)
💡 흐름 요약 메일 발송(카드 리스트) → 카드 클릭(내용 확인) → 통화 상담 시작 클릭 → 통화 시작 + Step 02 동시 진행
📌 도움말 신청자가 적은 정보 중 빠진 게 있으면 — 통화하면서 직접 입력하시고 💾 원본 시트에 저장 누르시면 됩니다.
📞
STEP 02

통화 + 메모 정리

대표님 2분
대표님이 하실 일
  • 통화 내용을 적은 메모를 textarea에 붙여넣기
  • ✨ AI 인사이트 추출 클릭 후 10초 대기
  • 확정 인원 / 1인 단가 직접 입력
  • 📥 시트 저장 → Step 3
자동으로 되는 일
  • 통화 핵심 / 추천 메뉴 / 고객 니즈 자동 요약
  • 1인 단가는 Step 3·4까지 자동 따라옴
  • 통화 메모도 시트에 자동 저장
💡 도움말 1인 단가 한 번만 정확히 입력하시면 — 견적서·메일·PDF에 모두 자동으로 반영됩니다.
📋
STEP 03

견적서 만들기

대표님 3~5분
대표님이 하실 일
  • 📋 견적서 시트 자동 생성
  • 📋 견적서 시트 열기 — 새 탭에서 시트 열림
  • 시트에서 단가 / 메뉴 / 수량 자유롭게 수정
  • 수정 끝나면 → Step 4 (발송)
자동으로 되는 일
  • 김민영 대표님 마스터 시트를 그대로 복제
  • 회사명·날짜·1인 단가·인원 자동 채움
  • 견적서·메뉴리스트 두 탭 같이 생성
⚠️ 꼭 기억해주세요 Step 4 발송 버튼은 시트를 한 번이라도 여셔야 활성화됩니다. 시트 안 보고 발송하는 실수를 막기 위한 안전장치예요.
📨
STEP 04

고객 발송

대표님 30초
대표님이 하실 일
  • 이메일 미리보기 확인 (수정 가능)
  • 📨 견적서 확정 + 자동 발송
  • 완료 안내 보고 → 완료 단계로
자동으로 되는 일
  • 견적서 PDF + 메뉴리스트 PDF 자동 발급
  • sobang@millcompany.co.kr 발신으로 메일 전송
  • 시트 상태도 "발송 완료"로 자동 변경
💡 도움말 메일 본문은 김민영 대표님 평소 양식 그대로예요. 단가·할인·시간 같은 건 그 자리에서 수정 후 발송 가능합니다.
💰
STEP 05

결제 확인

대표님 1분
대표님이 하실 일
  • 1차 입금일 (계약금·선급금·일시불 — 행사별 자유) 입력 (오늘 버튼)
  • 2차/최종 입금일 (잔금·중도금 — 행사별 자유) 입력
  • 사업자등록증 회신 여부 / 세금계산서 발급일
  • 최종 매출 (₩, 부가세 포함) + 작년 대비 성장률
  • 💾 시트에 저장
자동으로 되는 일
  • 시트 K~P 컬럼에 6가지 자동 기록
  • 매출 합계 자동 업데이트
  • 완료된 신청은 카드 색이 회색으로 변경
📝 N차 견적이 필요할 때 고객이 수정을 요청하면 → 카드 클릭 → 📝 견적 다시 보내기 누르시면 Step 3으로 자동 복귀합니다. 1차 견적은 그대로 보존되고 2차·3차가 새로 만들어져요.

막혔을 때 — 자주 있는 상황

대표님이 실제로 헷갈리실 수 있는 3가지만 정리했어요.

단계 사이 이동은 어떻게 하나요?
4가지 액션만 기억하세요

🟢 ① 보기 — 상단 STEP 01~05 카드
다른 단계 화면 잠깐 보고 싶을 때. 시트 안 바뀜, 신청자 모름. 안전.
예시: "발송 끝났는데 통화 메모 다시 보고 싶다" → STEP 02 카드 클릭
🟠 ② 재발송 — Step 5 화면 맨 아래 "📝 견적 다시 보내기 (2차)" 큰 주황 버튼
신청자한테 N차 견적 메일 다시 보낼 때. 클릭 한 방으로 자동 처리 (시트 상태 변경 + 차수 prefill + Step 3 화면 진입).
예시: "단가 잘못 보냈다, 수정해서 다시 보내야" → 큰 주황 버튼
⚠️ ③ 단계 변경 — 각 화면 상단 "⚠️ 단계 변경 ▾" 드롭다운
진행 중인 신청을 완전히 이전 단계로 돌릴 때만 사용. 시트 "상태" 컬럼 변경 + 사이드바 카드 위치 이동.
드롭다운 클릭 → 원하는 Step 선택 → 확인 모달 한 번 뜸 (실수 방지).
예시: "이 신청 취소·재시작해야 함" → 드롭다운 → "Step 1 신청 받기"
자주 쓰지 마세요. 보기만 하려면 ①번 (상단 STEP 카드) 사용.
🗑 ④ 정리 — 신청 카드 우상단 "정리" 버튼
중복·오입력 신청 정리할 때. 시트 row는 보존, 대시보드에서만 숨김.
예시: "신청자가 똑같은 신청 두 번 보냈다" → 잘못된 카드 정리
💡 가장 헷갈리는 ① vs ③: 🟢 ①번(상단 STEP 카드)은 잠깐 보기만 — 시트 안 바뀜. ⚠️ ③번(단계 변경)은 진짜로 단계 자체를 되돌림 — 시트 상태 변경. 모르면 무조건 ①번 사용 (안전).
실수로 다음 단계로 넘어갔어요. 되돌릴 수 있나요?
네, 됩니다. 각 화면 상단의 "⚠️ 단계 변경 ▾" 드롭다운을 누르시고 돌아가실 Step을 선택하시면 — 시트 상태까지 같이 되돌아갑니다. 확인 모달이 한 번 뜨니 실수로 누르셔도 안전해요.
알림톡(카톡 풍선)으로는 왜 자동 발송이 안 되나요?
케이터링 신청자분들이 회원가입 없이 폼만 작성하시는 구조라, 아임웹 자체 알림톡 기능으로는 자동 발송이 막혀 있어요 (아임웹 알림톡은 "회원" 대상으로만 작동).

대신 신청 접수 시점에는 SMS(문자)가 자동으로 나가고 있습니다 — "케이터링 접수가 완료되었습니다 + 소녀방앗간 카카오톡 채널 링크" 메시지가 신청자에게 발송되는 거 5/20에 확인했어요. 카카오톡 채널 링크가 들어있어서 신청자가 누르면 바로 대표님 채널로 들어옵니다.

견적서 발송 알림은 지금 메일로만 작동 중이에요 (PDF 첨부 + 본문 안내). 카톡 알림톡 연동(솔라피 솔루션)은 아직 안 붙여둔 상태라, 이관 시점에는 메일만 가는 구조입니다. 알림톡으로 받게 하실지 여부는 대표님 운영 판단 영역이고, 원하시면 "솔라피"(카카오 공식 인증 발송 서비스) 연결로 가능합니다 (영업일 2~3일 작업). 자세한 건 아래 "앞으로 보완 예정 ①" 참고해주세요.
AI가 추출한 내용이 좀 이상한데요?
AI 인사이트는 참고용이에요. 100% 믿지 않으셔도 됩니다. 텍스트 칸에서 직접 수정하시거나, 1인 단가·인원은 대표님이 확정값을 그대로 입력하시면 됩니다.
PDF는 어디 저장되나요?
현재는 병근 Google Drive에 자동 저장돼요. 메일에는 PDF가 첨부로 전달됩니다. 추후 김민영 대표님 Drive로 이관도 병근이 도와드립니다.

앞으로 보완 예정 (대표님 확인·결정 필요)

대표님께서 결정·승인해주셔야 추가로 자동화 가능한 부분 3가지입니다.

① 신청자에게 가는 알림 — 지금 어디까지 되고 있나

신청자가 받는 알림에는 두 시점이 있어요: ① 신청 접수 직후, ② 견적서 발송 후. 각각 어떻게 작동하는지 정리했습니다.

✅ ① 신청 접수 직후 — 문자(SMS) 자동 발송 중

신청자가 케이터링 폼 제출하면 아임웹이 자동으로 SMS를 보내고 있어요. 메시지 내용은 이렇게 갑니다:
"케이터링 접수가 완료되었습니다.
궁금하신 사항은 소녀방앗간 카카오톡을 통해 문의 부탁드립니다.
http://pf.kakao.com/_xbZlSM/chat"
→ 신청자가 링크 누르면 대표님 카카오톡 채널로 바로 들어와요. 즉, 카톡 알림톡은 아니지만 신청자가 카톡으로 대표님과 대화할 수 있는 다리가 이미 깔려 있는 셈입니다. (5/20 발송 이력 직접 확인)
📨 ② 견적서 발송 후 — 지금은 메일로만 작동 (알림톡 미연동)

대시보드 Step 04에서 "최종 발송" 누르시면 견적서 PDF가 신청자 메일함에 자동 첨부 전송됩니다. 메일 본문에도 안내 문구·총금액·일정이 포함되어 있어요. 카톡 알림톡 연동(솔라피)은 아직 안 붙여둔 상태라, 이관 시점에는 메일만 가는 구조입니다. 알림톡까지 같이 보낼지 여부는 대표님 운영 판단에 따라 아래 옵션에서 선택해주세요.
💛 카톡 풍선(알림톡)으로 받게 하고 싶으시다면

"솔라피"라는 카카오 공식 인증 메시지 발송 서비스를 연결하면 됩니다. 카카오가 직접 인정한 사업자라 안전하고, 회원가입 안 한 신청자에게도 알림톡이 정상적으로 갑니다 (카카오 정책상 알림톡은 채널 추가 안 한 분께도 발송 가능).

적용 시 이렇게 바뀝니다:
· 신청 접수 직후 → SMS 대신 카톡 알림톡으로 발송 (또는 둘 다)
· 견적서 발송 후 → "견적서가 메일로 발송되었습니다" 카톡 알림톡 자동 발송
· 비용: 알림톡 1건 ≈ 7~10원 (SMS보다 저렴), 월 100건이면 1,000원 안팎

준비 기간: 영업일 2~3일 정도면 전환 가능합니다.
· 솔라피 가입 + 우리 카카오 채널(_xbZlSM) 연동 → 당일
· 알림톡 메시지 양식(템플릿) 2개 카카오 재검수 → 1~2영업일 (이미 한 번 통과한 양식이라 재통과 거의 확실)
· 자동 발송 연결 코드 작업 → 2~3시간 (병근 작업)

💡 현재 셋업 = 신청 접수 SMS + 견적서 메일까지 작동. 알림톡 연동은 미적용 상태로 이관됩니다. 운영해보시고 "카톡으로 가야겠다" 판단되시면 그때 말씀해주세요.
② 견적서 PDF — 김민영 대표 Google Drive에 직접 저장

현재는 견적서 PDF가 병근의 Google Drive에 자동 저장됩니다. 메일에는 첨부로 정상 전달되지만, 원본 PDF 보관·검색은 병근 계정에서만 가능한 상태.

필요한 작업: 대표님 Google Drive에 전용 폴더(예: "케이터링 견적서") 만들고 권한 공유
→ 그 폴더에 자동 저장되도록 셋업 (병근 1줄 코드 수정)
→ 이후 모든 견적서 PDF가 대표님 Drive에 월별로 자동 정리됨
③ 견적서 메일 본문 — 이미지 풍부화

현재는 메일 본문이 텍스트 위주 + PDF 첨부. 보다 신뢰감 있는 인상을 위해 메뉴 사진·서비스 소개 이미지를 메일 본문에 함께 보여주는 구조로 개선 가능.

필요한 작업: 대표님 Drive에 메뉴 사진 폴더 공유 → 메일 발송 시 자동으로 본문에 inline 이미지 삽입
→ 신청자가 메일 열자마자 "어떤 케이터링인지" 시각적으로 인식
④ AI 인사이트 정확도 — 운영하시면서 단계 업그레이드 가능

대시보드 Step 02에서 통화 녹취·운영자 메모를 분석하는 AI는 3단계 옵션이 있어요. 김민영 대표님께 이관하면서 빠른 보급형 (현재 적용 중)으로 셋업해 두었습니다 — 빠른 응답·낮은 비용·충분한 정확도. 운영 자리잡고 더 풍부한 분석이 필요하시면 균형형/최고급으로 한 단계 올릴 수 있어요.

단계 특징 1건 비용 월 100건
균형형 더 풍부·정확 (단, 요청량 많으면 서버 응답 한도 초과 우려 — 운영 자리잡은 후 검토 권장) 약 ₩140 약 ₩14,000
빠른 보급형 (현재) 빠르고 합리적인 비용 + 충분히 풍부한 분석 — 일반 운영 권장 약 ₩30 약 ₩3,000
최고급 정밀형 통화 뉘앙스·복잡 요청까지 깊이 파악 — 대형·고가 행사에 적합 약 ₩500~700 약 ₩50,000~70,000
💡 운영하시면서 결정하세요
1~2개월 운영해보시고 "AI 분석이 좀 더 깊었으면 좋겠다", "통화 내용을 더 정확히 잡아냈으면" 하는 느낌이 오시면 병근에게 "AI 한 단계 올려달라" 한 마디만 주세요. 코드 한 줄 수정 + 즉시 전환됩니다 (배포 약 1~2분). 반대로 비용 줄이고 싶으시면 한 단계 내리는 것도 가능합니다.
