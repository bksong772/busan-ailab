유입 (Entry) — 채널·진입 경로

고객은 어디로 들어오는가
  • 오프라인 매장 (60%): 성수동·디큐브시티·이화여대·고속터미널·용산아이파크몰 5개 직영. 유동인구 거점 입점이 유입 전략. ⚠️ 워크인 손님이 매장 → 케이터링 고객으로 전환되는 사례 다수 (인터뷰: 웨딩 케이터링 손님이 알고 보니 매장 고객) — 그러나 매장 손님 데이터 0이라 깔때기 측정 불가
  • 케이터링·명절 B2B (40%): 거의 100% 바이럴 유입. DB손해보험·대법원·KB·현대해상 등 8년차 재구매 고객 다수
  • 케이터링 신청 채널: 자사 홈페이지(아임웹) 신청서 → 단일 진입점
  • SNS·디지털 마케팅: 거의 0. 작년 임팩트프랜차이즈로 SNS 에이전시 월 100만원 시도 (효과 불투명)
유입 진단: 매장 ↔ 케이터링 깔때기는 명백히 작동 중 — 단, 측정 불가. 디지털 마케팅 시도 1회 후 효과 미검증.

입력 (Input) — 어떤 정보를 수집해야 하는가

DB 필드·컬럼 정의
  • 케이터링 신청서 (아임웹): 회사명·담당자·행사일·인원·예산·메뉴 요청·장소·연락처 — 충실
  • 견적서 (구글시트): 인원·메뉴 구성·출장 인력·현장 운영비·총액 — 단, 전화 상담 통해 수동 정제 필수
  • 채널톡: 고객 ID·대화 히스토리 영구 보관 — 재구매 자산
  • 구글시트 (2017~): 8년치 케이터링 누적 DB / ERP 카운트: 물류·재고
  • POS: 매장 매출만 기록 (고객 정보 X)
  • ⚠️ 매장 워크인 필드 = 0 — 시간대·고객군·동행수·단골 여부 모두 미수집
  • ⚠️ 매장 → 케이터링 전환 추적 = 0 — 워크인 ID ↔ 케이터링 신청자 매칭 불가
입력 진단: 케이터링 쪽 필드는 8년치 누적으로 충실. 매장 쪽은 매출만 있고 운영 데이터 0 — 누가·언제·어떻게 들어오는지 안 잡힘. (매장 데이터 활용 가설은 검증 안 됨 → P3 장기 과제로 별도 분리)

▼ 처리 규칙·분기

  • 금액 분기: 800만원 이상 → 현장 사전 방문 / 그 이하 → 사진 대체
  • 재구매 B2B 분기: 신청서·견적 메일 생략 → 채널톡 직행
  • 가격 룰: 매장 1만원 사수 (9,800원) — 12년간 6천→9.8천 단계적 인상 / 케이터링 1인당 3~5만원 (프리미엄)
  • 메뉴 결정 룰: "지역 식재료·본연의 맛" 우선, 트렌드 후순위 / 저염·무조미료
  • 농가 조달 룰: 시니어클럽 거점 단위 (개인 농가 X — 법인 증빙 필수) / 시니어클럽 가공품 월 4~5천만 + 가락시장(서울 송파 농수산물도매)·육류 월 3천만
  • ⚠️ 커스터마이징 룰 = 룰북 미정립: 대표 + 10년차 팀 리더의 경험·감 기반. 팀원은 "이건 우리가 받아도 되는 건가?" 판단 어려움 → 표준 외 요청은 보류 → 모든 케이스가 결국 대표·팀리더의 최종 판단으로 모임 (레버 핵심)
"구글시트 쓰기 권한은 저랑 팀리더만요. 커스터마이징 판단이 필요해서." — 김민영 대표 (룰의 사람 의존)

고객이 받는 최종 가치

  • 차별점 3: 케이터링 200가지 메뉴 가능 — "예쁘면서 맛있는, 실속 케이터링" (김민영 대표 자체 정의)

  • 케이터링 재구매율: 80% — "재구매 만드는 방법: 똑같은 거 받으시면 지루하시니 계속 바꾼다"

확보 (Retention) — 어떻게 돈 벌고 묶어두는가

수익화 + 리텐션 구조

▼ 수익화 구조

  • 매장 60% : 케이터링 40% / 케이터링 수익률 = 매장의 약 2배 (임대료 부담 X)
  • 임대료 압박: 용산 월 2천만 / 성수동 4배 상승 → 케이터링 비중 확대 압력

▼ 리텐션 (작동 중) ✓

  • B2B 재구매율 80% — 비결: "지루하지 않게 매번 메뉴 변경"
  • 전화 상담 전환율 ~100% — 부티크 1:1 응대
  • 8년차 충성 고객: DB손해보험·대법원·KB·현대해상
  • 채널톡 영구 히스토리 — 재구매 시 신청서·견적 단계 생략

▼ 리텐션 (누락 = 검증 후 결정) ✗

  • 매장 멤버십 ✗ — 매장 고객 식별·관리 시스템 부재 (POS 외주라 카드 데이터도 추출 불가)
  • 매장 운영 통계 ✗ — 시간대·고객군·동행수 등 운영 의사결정용 데이터 자체가 없음
확보 진단 (4줄로 풀어쓰기):
  • B2B 케이터링 리텐션은 이미 천장 — 재구매 80% + 전환율 ~100%. 손볼 곳 없음.
  • 매장 쪽은 운영 데이터 0 — 누가·언제·어떻게 오는지 안 잡힘.
  • "매장 고객이 케이터링으로 넘어온다"는 가설은 검증 안 됨 (페르소나 다를 수 있음 + POS 외주로 추출 불가) → 장기 검증 과제로 분리.
  • 확보 단계의 적정 방향 = 신규 시스템보다 효율 개선 우선 (구체적 AX 과제는 다음 섹션에서).

03

핵심 AX 과제 도출 (6건)

3건 이상 ✓
왜 P1+P2가 메인? — 강한 BM의 적정 솔루션 = 효율 개선

전환율 ~100% · 재구매율 80% — 이미 천장에 닿은 강한 BM. 이 단계에서 검증 가능한 효과는 신규 솔루션이 아니라 효율 개선(P1+P2): 응답 24h+ → 즉시 / 입력 월 10h → 0h / 월 50만원 절감. 8년 DB의 맞춤 제안서·SaaS화는 효율 개선 후 신규 모객 단계(P5)에서 진행.

→ 대표 직접 호응 + 진단 결과 + 정량 검증 가능 = 3박자 일치한 5주 메인.
