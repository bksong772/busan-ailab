1

유입 (Entry) — 채널·진입 경로

고객은 어디로 들어오는가
  • 오프라인 매장 (60%): 성수동·현대백화점·이화여대·고속터미널·용산아이파크몰 5개 직영. 유동인구 거점 입점이 유입 전략. ⚠️ 워크인 손님이 매장 경험 후 케이터링·명절 선물 고객으로 전환되는 사례 다수 (인터뷰: 예산 웨딩 케이터링 손님이 알고 보니 매장 단골) — 그러나 매장 손님 데이터 0이라 깔때기 측정 불가
  • 케이터링·명절 B2B (40%): 거의 100% 바이럴 유입 (소개·경험 기반). DB손해보험·대법원·KB·현대해상 등 8년차 재구매 고객 다수
  • 케이터링 신청 채널: 자사 홈페이지(아임웹) 신청서 → 단일 진입점
  • SNS·디지털 마케팅: 거의 0. 작년 처음으로 경기도 사회적경제원 임팩트프랜차이즈 통해 SNS 에이전시 월 100만원 시도 (지속 여부 불투명)
  • 대표 본인은 매장·케이터링 외 유료 트래픽 의존도 거의 없음을 강점으로 인식
2

입력 (Input) — 어떤 정보를 수집해야 하는가

DB 필드·컬럼 정의 + 누락 진단
  • 케이터링 입력 흐름: 아임웹 신청서 → 전화 상담 (대표 + 10년차 팀 리더 단 2인만 응대) → 구글시트 수동 정리 → 이메일 견적서 → 채널톡 상세 소통
  • 아임웹 → 구글시트 자동 연동을 한 번 시도했으나, 전화 상담 중 정보 정제가 필요해 수동으로 회귀
  • 800만원 이상(50~60인+) 행사: 현장 사전 방문 / 그 이하: 사진으로 대체
  • 재구매 B2B 고객: 신청서·견적 메일 단계 생략 → 채널톡으로 직접 소통
  • 고객 정보 관리: 구글 스프레드시트 단일 (CRM 미도입)
"구글시트 쓰기 권한은 저랑 팀리더만요. 커스터마이징 판단이 필요해서." — 김민영 대표
3

로직 (Logic) — 데이터 출처 + 처리 규칙

출처·룰의 사람 의존도
  • 수익 1순위는 케이터링. 매장 대비 수익률 약 2배 (임대료 부담이 없는 구조)
  • 메뉴 결정 로직: 트렌드보다 "지역 식재료 → 본연의 맛"이 1순위. 저염·무조미료(MSG·소금·설탕 최소) 정책 유지
  • 농가 150곳은 오해: 실제로는 지역 시니어클럽/거점 조직 단위로 소통 (개인 농가는 법인 증빙 처리 불가). 월 4~5천만원 가공품 + 가락시장·육류 월 3천만원
  • 가격 결정: 원가·임대료 기반의 정성적 판단 (밥 한 그릇 9,800원 — "1만원 사수")
  • 케이터링 커스터마이징은 대표 + 10년차 팀 리더의 경험·감 기반. 명시적 룰북·체크리스트 부재 (팀원 레벨에서는 "예외 가능 여부" 판단이 어려워 단순 거절로 응대)
  • 임대료 압박: 용산 월 2천만, 성수동은 4배 상승 → 케이터링 비중 확대 압력
"지금 BM을 보면 케이터링이 수익률이 더 높겠네요." → "맞습니다, 약 2배. 임대료가 없어서요." — 송병근 ↔ 김민영 대표
4

결과 (Output) — 산출물·KPI·핵심가치

고객이 받는 최종 가치
  • 핵심 가치 메시지: "지역 식재료를 도시에 전하자". 제일 맛있는 게 아니라 본연의 된장 맛. 농가 안정 소득 + 도시민 건강한 한 끼
  • 차별화: 모든 원재료 정보·재배자 이름 공개 / 계약재배 (풍흉년 무관 계약금 지급) / 전통 발효 조리
  • 케이터링 전환율: 전화 상담 시 거의 100% (실질 95%+) — "여러 데 전화해 봤는데 이렇게 상세한 상담이 처음"이라는 고객 피드백. 자동 견적으로 대체 시 이탈 우려 큼
  • 케이터링 재구매율: 80% (마케팅 비용 거의 0인 채로 유지)
  • 고객이 가장 만족하는 포인트: 정직한 식재료 + 합리적 가격 + 도시인의 힐링 한 끼라는 정서적 가치
5

확보 (Retention) — 어떻게 돈 벌고 묶어두는가

수익화 + 리텐션 구조
▼ 수익화 구조
  • 매장 60% : 케이터링 40% (2024 매출 30억 기준 = 매장 ~18억 + B2B 케이터링·명절 ~12억)
  • 케이터링 수익률 = 매장의 약 2배 (임대료 부담 X). 임대료 압박이 큰 매장(용산 월 2천만, 성수동 4배 상승)에서 케이터링으로 무게중심 이동 자연스러움
  • 유료 트래픽 의존도 거의 0 — 매장 입지 + 바이럴이 모객의 핵심 / SNS 에이전시 월 100만원이 유일한 외주 마케팅
▼ 리텐션 — 작동 중 (강력한 BM ✓)
  • B2B 케이터링 재구매율 80% — 비결: "지루하지 않게 매번 메뉴 변경" (대표 직접 발언)
  • 전화 상담 전환율 ~100% (실질 95%+) — 부티크 1:1 응대. 자동 견적이 오히려 이탈 유발할 정도로 검증된 운영
  • 8년차 충성 B2B 고객: DB손해보험·대법원·KB·현대해상 — 마케팅 비용 거의 0인 채로 유지
  • 채널톡 영구 히스토리 — 재구매 시 신청서·견적 단계 생략 → 커뮤니케이션 마찰 0
  • 2017년부터 케이터링 DB 누적 (8년치) — 활용 0 (대표: "한 번도 그런 거 못 해봤어요") 이지만 자산은 누적 중
▼ 리텐션 — 누락 (AX 기회 ✗)
  • 매장 멤버십 ✗ — 매장 단골 식별·관리 시스템 부재. POS는 외주 업체라 카드 결제 데이터 추출 불가
  • 매장 → 케이터링 전환 추적 ✗ — 워크인 손님이 B2B로 전환되는 사례 다수인데 측정 불가능
  • 선제 케이터링 제안 ✗ — 들어오는 의뢰만 응대 (대표 + 팀 리더 2인 처리 한계)
  • 잠자는 B2B 고객 follow-up ✗ — 8년 DB의 1년 미접촉 고객 깨우기 시스템 부재
▼ 디지털 도구 스택 (참고)
  • 구글 스프레드시트 — 케이터링 고객DB·견적·진행단계
  • KT비즈메카 메일+게시판 — 지출결의·내부서류·파일공유
  • ERP (카운트) — 물류 입출고 / 아임웹 — 홈페이지·케이터링 신청서
  • 카카오 채널톡 — 케이터링 고객 소통 (히스토리 영구 유지)
  • AI 툴 미사용. 대표 개인적으로 GPT 가끔. 팀원들은 새 툴 도입에 허들 인식. 단, 도입 의향 명시 — "재무 부분을 클로드로 전환하면 좋겠다"
"재구매를 만드는 방법요? 똑같은 거 받으시면 지루하시니까 계속 바꿔요. 그게 저희 부티크 방식이에요." — 김민영 대표 (재구매율 80% 비결)
확보 단계 진단: B2B 리텐션 80% — 이미 천장. 매장 리텐션 0 — 진짜 구멍. 매장 funnel 잡으면 케이터링 깔때기 입구가 넓어진다는 가설. 단, ① 매장 고객 페르소나(동네 점심) ≠ 케이터링 담당자 페르소나(회사 비서·인사)일 가능성 ② POS 외주로 카드 데이터 추출 불가 ③ 매장→케이터링 전환은 매장에서 맛 경험 → 회사 행사 떠올림 → 의뢰 흐름이라 매장 데이터로 측정 어려움 — 이 3가지 한계로 5주 메인 X / 장기 검증 과제로 분리.

⚠️ 왜 5주 메인이 아닌가? (3가지 한계)
  1. 페르소나 가설 약함: 매장 단골(동네 점심 자주 오는 개인) ≠ 케이터링 담당자(회사 비서·인사팀)일 가능성 큼. 인터뷰 1케이스를 시스템 인프라까지 일반화는 무리.
  2. POS 외주: 결제 시스템이 외부 업체라 카드 결제 데이터 추출 불가 → 단골 식별 정확도 떨어짐. 자체 태블릿 입력은 직원 부담 + 정확도 ↓.
  3. 강한 BM 단계의 ROI: 전환율 ~100% · 재구매 80%인 BM에서 신규 솔루션 효과 검증 어려움. 효율 개선(P1+P2)이 적정 솔루션.
대신 권고: P1+P2 5주 가동 후, 워크샵 #2~3에서 매장 데이터 가설을 단계적으로 검증. 작은 PoC (1개 매장 + 1주 수기 기록)부터 시작해 페르소나 가설부터 확인.
→ 장기 임팩트: 가설 검증 후 진행 시 케이터링 매출의 매장 출처 비중 가시화, 시간대별 운영 효율화, 매장 단골 → 케이터링 선제 제안.

→ 기대 효과: 콘텐츠 제작 시간 70% 절감, 발행 주기 안정화, 외주비 월 100만원 → 0원 전환 가능.
5주 컨설팅 집중 제안

5주 내 실제 구동 가능한 솔루션은 P1 (케이터링 견적서 웹화)를 메인으로 추천. 대표가 가장 큰 호응을 보였고, 전화 상담 → 견적 전달 흐름의 약한 지점을 정확히 보완하는 솔루션이며, ROI 가시화가 빠르다(첫 견적 발송 직후 측정 가능).

P2 (아임웹 자동 연동)은 P1 구축 과정에서 부수적으로 함께 구현 가능. P3 (매장 워크인 데이터 · 안재은 코치 준비)는 매장→케이터링 깔때기 가시화의 첫 단계로 5주 내 MVP 가능 — 시간대별 운영 효율화 + 단골 식별로 즉시 임팩트. P4 (재무 AI)는 5주 내 PoC만 보여드리고, P5·P6은 최종 발표(5/27) 시 "확장 로드맵"으로 제안하는 구조가 가장 현실적이다.

B. 10년치 케이터링 DB 활용 논의

안재은 코치 제안 → 송병근 코치 후속 검토 (팀 토론)

▶ 안재은 코치 제안: 소녀방앗간은 2017년부터 모든 케이터링 고객 데이터를 보유 (성함·연락처·소속·메일·예산·메뉴·만족도) — 약 10년치 DB가 구글시트와 채널톡에 적재돼 있다. 그러나 견적서 작성·메뉴 제안 시 이 DB를 시스템적으로 활용하는 단계는 부재. 매번 대표·팀 리더의 기억에 의존해 새로 구성하는 구조 → 견적서에 기존 DB를 활용하면 큰 효율 개선 가능.
⚠️ 송병근 코치 후속 검토 (현실 점검)
"데이터 활용"이 명확한 기회임은 동의. 다만 인터뷰 분석상 "이미 할 수 있었다면 진작 했을 것"이라는 점에 주목해 "왜 그동안 못 했는지"를 먼저 진단해야 함:

① 케이터링이 매번 고도의 커스터마이즈가 필요해 표준 DB 검색이 오히려 비효율일 가능성
② 대표·10년차 팀 리더의 머릿속 매칭이 시스템보다 빠를 수 있음 (현재 전화 상담 거의 100% 전환율 = 그 자체로 검증된 운영)
③ 데이터 정제·구조화 비용 vs 활용 빈도 ROI 검증 필요
팀 합의 결론
전면 DB 시스템 신축이 아니라, "대표·리더의 빠른 검색·참조를 보조하는 채널톡 통합 검색 도구" 수준이 현실적. P5 (케이터링 SaaS) 내 "과거 견적·메뉴 검색" 기능으로 단계적 접근 — 5주 안에 풀 시스템 만들지 않고, 정말 자주 쓰이는 검색 패턴부터 가볍게 검증.
