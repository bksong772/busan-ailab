요 며칠 — 솔직한 고충

HONEST
🔌 고충 1 — "아임웹 신청을 우리 대시보드로 가져오는 데 4일" 가장 큰 벽이었다. 아임웹 고객센터에 문의해도 "안 됩니다"라는 답뿐이었고, 5월 비비AI로 전환되면서 답을 얻을 수는 있었지만 — "불가능한 일에 대한 단서"는 끝까지 안 줬다.

→ 직접 다 뜯어봤다. 결국 발신자 메일(SMTP)을 내 메일로 전환하는 방식으로 우회 → 신청이 내 메일함에 도착 → 내 코드가 메일을 읽고 시트에 적재. 4일 만에 성공.
📵 고충 2 — "아임웹 알림톡 자동 발송도 막혀 있다" 신청 들어오면 자동으로 알림톡 보내고 싶었는데 — 아임웹은 외부에서 알림톡 발송 트리거를 막아둠. 문의해도 "구조적 한계"라는 답.

→ 솔라피라는 외부 카카오톡 솔루션으로 우회 진행 중. 월 100건 ≈ 1,000원으로 자동 발송 가능.
🧩 고충 3 — "한 화면 안에서 다 연결되어야 의미가 있다" 가장 큰 고충. 대시보드 밖으로 한 번이라도 나가야 하면 자동화(효율화)의 가치가 사라진다. 시트는 시트대로, 메일은 메일함에서, 알림톡은 카카오 콘솔에서... 흩어져 있으면 차라리 안 쓰는 게 낫다.

→ 신청 → 통화 → 견적 → 발송 → 결제 확인까지 — 한 화면에서 클릭만으로 끝나도록 흐름을 잇는 게 1주일 작업의 본질이었다.
교훈: 자영업자 AX의 벽은 "기술 어려움"이 아니라 "외부 플랫폼이 막아둔 구조적 한계"다. 우회 솔루션을 찾고 한 화면으로 잇는 것이 진짜 작업.
06

김민영 대표 자립 운영 — 어디까지 왔나

AUTONOMY
단계 현황 상태
① 신청 수신 아임웹 → Gmail OAuth 폴링 → 시트 자동 적재 (5분 간격) 자동
② 통화 + AI 인사이트 녹취 paste → 견적서 초안 JSON 자동 생성 자동
③ 견적서 시트 생성 김민영 마스터 시트 복제 + 차수 자동 반영 + 단가/인원 자동 채움 자동
④ 시트 단가 수정 김민영 대표가 시트에서 직접 단가·메뉴 조정 (8년 노하우 반영) 대표 1번 클릭
⑤ PDF + 메일 발송 "견적서 확정" 1버튼 → 시트 PDF 자동 + 본문 자동 + 신청자 발송 1버튼
⑥ N차 재견적 "다시 보내기" 클릭 → 직전 시트 복제 + 차수 라벨 자동 1버튼
⑦ 결제 확인 입금 들어오면 6필드 입력 → 시트 row 자동 완성 대표 입력
⑧ 알림톡 #2·#3 카카오 비즈채널 심사 결과 대기 중 (1~3 영업일) 심사 대기
결론: 8단계 중 6단계 자동 / 2단계는 대표 클릭 1번. 알림톡 심사만 통과하면 100% 자립 운영 가능.

1주일 학습 — 자영업자 AX의 진짜 작업

LEARNING
학습 ① — 디테일이 신뢰다

도장 잘림, 차수 라벨 오류, 신청일시 새벽 시각 — 이런 게 한두 개 보이면 전체 시스템 신뢰가 깎인다. 큰 그림보다 마지막 5%가 클라이언트 인상을 결정한다.

학습 ② — 양식은 만드는 게 아니다

김민영 대표 8년 양식을 코드로 다시 그리는 건 자만이었다. 시트 복제 + 자동 채움이 정답. 클라이언트 자산을 존중하는 게 시작점.

학습 ③ — 반응 속도가 곧 UX

DB도 빠르고 코드도 빠른데 체감이 느렸다. 원인은 full reload. client-side 전환으로 바꾸니 "DB 문제인 줄 알았다"는 답답함이 사라졌다.

학습 ④ — 안목은 협업으로 메운다

디자인 안목 부족은 사실이다. 대신 UX·브랜딩·카피 에이전트 3명에게 동시에 의견 받고 통합. 혼자 결정하지 않아도 된다.

한 줄로: 자영업자 AX는 "신기술 도입"이 아니라 "8년 노하우를 코드로 보존하는 일"이다.
