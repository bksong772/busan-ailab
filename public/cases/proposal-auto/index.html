📋 8단계 풀 사이클

  1. ① 진완(영업)이 기관과 통화 — 폰 자동 녹음·STT
  2. ② 통화 종료 → 폰 자동 STT 변환 (텍스트 즉시)
  3. ③ 노션 거래 row 만들고 STT 그대로 붙여넣기
  4. ④ Claude Code 한 줄: "이 STT로 제안서·견적서 만들어줘"
  5. ⑤ 노션 row가 자동으로 표준 템플릿으로 정리 (거래개요·할일·STT 풀텍스트·운영설계)
  6. ⑥ 제안서 HTML 4~5p 자동 작성 (단성고 톤)
  7. ⑦ 견적서 HTML + (주)크리플레이 도장 자동 (강사료 + 교구비 분리)
  8. ⑧ git push → Vercel 자동 배포 → 라이브 URL 즉시
